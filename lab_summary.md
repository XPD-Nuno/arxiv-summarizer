In this lab I built a small arXiv client that fetches Atom XML, parses results into structured data, and generates a readable report from a CLI. The main challenge was handling XML structure reliably and keeping requests polite with a delay to avoid hitting rate limits. I solved it by separating responsibilities into an API module and a parser module and writing unit tests with mocks to validate URL building, parsing, and error handling. Next I would improve the search UX further and add export options like Markdown or JSON output.
